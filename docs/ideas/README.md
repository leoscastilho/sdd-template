# Idea briefs

Non-normative. Each file here is the written-up result of a discussion about a feature, produced by `/idea` and meant to be converted into a real spec with `/spec-new`.

**These are not specs.** They carry no frontmatter, no id, no acceptance criteria, and nothing here governs any code. If a brief and a spec disagree, the spec wins — and the brief is stale history the moment the spec exists.

They live in `docs/` rather than `specs/` on purpose: every `.md` under `specs/` is lint-checked for spec frontmatter, so a free-form file there would break `make spec-lint` and block commits.

Kept because the *why* behind a spec — particularly the options that were considered and dropped — is worth more later than it looks now.
