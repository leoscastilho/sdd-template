# Optional configuration examples

These files are examples to copy only after your project's architecture is chosen.
They are not active starter configuration and do not prescribe a stack.

- `typescript/tsconfig.base.json`: strict TypeScript baseline for a project that
  chooses a modern bundler. Adjust the target and module settings for your runtime.

Spec templates live under `specs/00-product/` through `specs/04-decisions/`.
